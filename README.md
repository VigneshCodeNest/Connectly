# Connectly 💬

Connectly is a full-stack real-time messaging web application built using React.js, Spring Boot, and MySQL.

## 🚀 Features

- User Registration & Login
- JWT Authentication
- User Search by Email
- Connection Requests
- One-to-One Messaging
- Group Messaging
- Text, Image, Video & Sticker Messages
- Reply, Forward, Delete & Star Messages
- Sent, Delivered & Read Status
- Text & Image Status with 24-hour Expiration
- Mute Chat Notifications
- Block/Unblock Users
- Change Password
- Real-time Messaging using WebSocket

## 🛠️ Tech Stack

**Frontend**
- React.js
- JavaScript
- HTML5
- CSS3

**Backend**
- Java
- Spring Boot

- Spring Data JPA / Hibernate
